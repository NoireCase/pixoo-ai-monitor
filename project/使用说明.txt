Pixoo AI 监控 Windows 预览版

解压整个发行目录，双击“Pixoo AI 监控.exe”。不要移动或删除 _internal 等资源。

首次使用：在 Windows 中配对 Pixoo，在软件“设备”页配置地址和端口；在“服务”页更新需要的密钥。Codex 数据要求本机已安装并登录 Codex CLI。点击“开始工作”后软件开始连接和轮播。

关闭窗口会隐藏到托盘，后台继续工作；需要停止时点击“停止工作”。“设置”中可由用户自行启用或关闭登录后自动开始。

配置和日志存放在当前 Windows 用户的 %LOCALAPPDATA%\Pixoo AI Monitor V1；API Key 使用 Windows 凭据管理器。

旧版升级：先停止旧后台并等待退出，备份配置，再启动新版，避免蓝牙连接冲突。回滚时先停止新版再启动旧版。若旧版未安装在原默认路径，需手动核对和迁移配置。

六页真实 Pixoo 画面已由用户目视确认；锁屏、睡眠、登录自启、跨设备长期运行及无 Python 电脑仍需进一步验收。详细说明、源码和许可证见 https://github.com/NoireCase/pixoo-ai-monitor 。
